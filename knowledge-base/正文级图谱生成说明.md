# 正文级知识图谱生成器

本脚本从仓库中的 PDF 提取可检索的条款标题、页序、标准编号提及和主题词，并生成/更新 `knowledge-base/graph.json`。

## 运行

在仓库根目录执行：

```bash
python -m pip install -r requirements-knowledge-graph.txt
python scripts/build_knowledge_graph.py
```

脚本只在本地读取 PDF，不会上传文件。重新运行会重建图谱 JSON；提交前请检查差异和抽取报告。

## 图谱内容与关系

- `document`：源 PDF，记录仓库相对路径、大小和 Git blob SHA。
- `provision_heading`：规则识别出的条款号、条款标题和 PDF 页序；仅保存标题，不复制条款正文。
- `standard_reference`：正文中匹配到的标准编号。`mentions_standard_identifier` 只代表正文出现编号，不代表规范性引用或版本替代关系。
- `topic`：由脚本顶部可编辑的主题词表匹配。关系是词面命中，不是法律适用性判断。
- `extraction_report`：逐文件给出抽取状态、页数和识别数量。扫描件/图片 PDF 会标记为 `no_extractable_text_ocr_needed`。

## 准确性边界

这是机器抽取草稿，不是经过法律专业人员核验的合规结论。条款编号格式、标题切分和标准编号识别可能有误；PDF 页序不一定等于印刷页码。尤其不能根据编号出现推断标准现行有效、被引用、替代或废止。建议逐条对照原文件复核，并在后续工作流中添加 OCR 和人工审核状态。
