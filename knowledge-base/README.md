# 法规标准库知识图谱

本目录是仓库文件的可追溯知识库初始版，包含 `graph.json`（实体与关系）和本说明。

## 当前覆盖范围

- 索引仓库根目录全部 **18 个文件**：17 个 PDF 和 `README.md`。
- 每个文件节点记录仓库相对路径、格式、文件大小和 Git blob SHA，便于追溯源文件。
- 标准编号与年份仅在文件名可辨认时记录。
- 文件名明确表达的主题已建为主题节点，并通过边关联；同为 6441 编号的两份文件仅标注“同标准编号”，不推断新旧版替代关系。

## 使用方式

`graph.json` 为 UTF-8 JSON，`nodes` 包含 `document` 与 `topic` 节点，`edges` 描述节点间关系。文档可通过 `path` 定位到仓库中的原文件，也可通过 `sha` 校验源文件身份。关系类型及证据写在每条边的 `type`、`evidence` 和 `confidence` 字段中。

## 重要限制

当前执行环境可读取仓库文件清单及元数据，但没有对 PDF 正文进行文本抽取。因此，这是一份**文件级目录与标题级关联图谱**，不是条款级法规知识库。正文中的定义、义务、责任主体、适用范围、条款引用以及生效/废止/替代关系都尚未抽取；不应将文件名推断当作法律或合规结论。

要生成正文级图谱，需对 PDF 做文本/OCR 抽取，再逐篇抽取“标准/法规—条款—主题/对象—要求/责任—引用文件”实体关系，并保留页码、条款号及原文证据，最后人工核验。扫描件还需 OCR；抽取结果应与本图谱的源文件 SHA 关联，避免版本混淆。
